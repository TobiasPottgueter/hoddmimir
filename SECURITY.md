# Security policy

## Supported versions

Hoddmímir 2.0 is under active development. Security fixes are applied to the
current default branch and, once releases exist, to the latest supported
release line. The legacy project and its 1.x code are not maintained here.

## Reporting a vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/TobiasPottgueter/hoddmimir/security/advisories/new)
for this repository. Do not open a public issue for a suspected vulnerability.

Include the affected component and version or commit, impact, reproduction
steps, and any suggested mitigation. Remove credentials, tokens, private hosts,
customer data and other secrets from every report and attachment.

The maintainers will review the report privately, coordinate validation and a
fix, and agree on disclosure before public details are published.
